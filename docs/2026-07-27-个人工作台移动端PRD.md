# 个人工作台移动端 PRD

- 状态：草案
- 负责人：待定
- 创建日期：2026-07-27
- 最后更新：2026-07-29

## 1. 背景与目标

个人健康、学习和待回看的信息分散在多个应用，用户需要在一个手机端工作台内完成当天喝水、运动、体重、护肤和韩语学习的查看与记录，并把有价值的内容沉淀为可分类查阅的文章。

本期目标是提供一个以“今天”为默认入口的移动端独立应用体验：用户可在 30 秒内看到当天计划和进度，并在单次操作后完成一条健康或学习记录。数据需绑定个人账号并支持云端同步，为后续桌面端接入保留同一数据源。

## 2. 用户角色

| 角色 | 权限与诉求 |
| --- | --- |
| 个人用户 | 查看自己的任务与历史；新增、修改和删除自己的记录；学习《首尔大学韩国语》课程内容。 |
| 系统管理员 | 维护课程、视频和默认任务模板；本期不提供管理端页面。 |

## 3. 使用场景

1. 早晨打开应用，查看今天要完成的护肤项目和韩语课程进度。
2. 喝完一杯水后点击对应的杯子图形，即时更新今日 8 杯饮水进度。
3. 运动结束后选择羽毛球、游泳、徒步或跑步，记录时长和距离；徒步记录额外填写地点、所爬山峰或路线名称。
4. 晨起称重后录入体重，按周查看折线趋势和历史数据。
5. 晚间完成面膜或基础护肤后勾选当日任务，回看当月完成情况。
6. 学习《首尔大学韩国语》某一课时，收听单词和句子发音，标记生词，查看语法与关联教学视频。
7. 用户收到或整理一段值得留存的内容时，点击“记录到知识库”，将内容、图片和备注保存成文章，之后按分类目录回看。

### 4.2 接口依赖

| 接口能力 | 用途 | 关键字段 |

| 认证与用户信息 | 获取当前用户与数据隔离 | userId、昵称、头像、时区 |
| 日记录读写 | 读写饮水、运动、体重、护肤记录 | recordId、date、type、value、createdAt、updatedAt |
| 课程目录与详情 | 获取课程内容与学习状态 | courseId、lessonNo、vocabulary、sentences、grammar、textVideoUrl、workbookVideoUrl、progress |
| 发音服务 | 返回单词或句子的韩语音频 | text、language、audioUrl、durationMs、version |
| 每日学习内容 | 返回当天 AI 学习视频和文字总结 | learningDate、contentId、title、sourceName、videoUrl、durationSec、summaryItems |
| 知识库文章读写 | 保存、读取、删除文章及其分类、备注和压缩图片 | articleId、userId、title、category、content、note、imageDataUrl、source、createdAt |
| 知识库自动录入 | 接收 Codex 整理的文章并写入指定个人账号 | ownerEmail、title、category、content、note、ingestToken |

### 4.3 权限规则

- 未登录用户可浏览和使用本机记录；点击“使用邮箱登录”后输入有效邮箱，系统发送登录链接。未登录状态不写入云端。
- 登录用户只能读取和操作 `userId` 与当前账号一致的数据。
- 知识库自动录入接口不接受浏览器公开密钥；仅携带 Supabase Functions Secret 的服务端调用可通过，并按 `ownerEmail` 匹配已登录用户。
- 课程视频无播放权限或链接失效时，显示“暂时无法播放，请稍后重试”。

## 5. 功能流程

### 5.1 今日记录

1. 用户进入“今天”，客户端按当前时区加载当天汇总数据。
2. 用户点击一个空杯图形或完成某项护肤任务。
3. 客户端先更新已完成杯数或任务状态，随后提交记录。
4. 服务端写入成功后更新同步时间并提示“已保存”；失败时恢复可重试状态并提示“保存失败，请检查网络后重试”。

### 5.2 运动与体重

1. 用户进入对应模块，点击“记录运动”或“记录体重”。
2. 运动记录需选择类型并填写时长或距离至少一项；选择徒步时还需填写地点、所爬山峰或路线名称。客户端校验类型、时长、距离、徒步路线和体重范围。
3. 服务端返回记录 ID 后，同日记录按最新提交内容覆盖；当月次数、总时长、总距离、项目分布和按日记录即时重新计算。
4. 用户删除记录时需二次确认；确认后服务端软删除，列表即时移除并提示“记录已删除”。

### 5.3 护肤

1. 默认打开今天的任务清单，基础护肤为每日默认项，其余任务由用户当日勾选完成；每项任务显示对应图标。
2. 用户可填写护理内容和图标后点击“添加护理”；系统校验名称非空、长度不超过 20 个字且不与已有名称重复，新增任务立即加入今天清单。
3. 勾选或取消勾选后，保存该日期和任务类型的完成状态。
4. 切换“本月”后按自然月展示日期；每个日期直接展示当天完成护理的图标，点击日期显示当天已完成的护理名称。

### 5.4 韩语学习

1. 用户在“韩语学习”看到第 1-10 课列表，点击任一课切换至对应内容；上次打开的课次在本机保存并作为下次默认课次。
2. 页面依次展示本课单词、示例句、语法说明、课文讲解和练习册讲解；单词和句子旁提供“播放发音”。
3. 用户可切换学习区块；点击播放发音请求对应韩语音频，点击视频后在当前工作台的页内播放器加载来源页面，不打开新窗口或跳转离开工作台。
4. 课文讲解来自用户提供的公开抖音合集口令；未获得可核验的直达 URL 时，展示合集口令和搜索入口，不将搜索结果误标记为指定合集视频。
5. 练习册讲解仅在已核验到课次的公开视频时展示直达链接；未匹配的课次展示“该课尚未核验到公开匹配视频”。
6. 用户点击“标记生词”后保存单词和标记时间；再次点击可取消标记。
7. 点击“标记本课已学完”后保存完成时间，并更新课程进度。

### 5.5 AI 学习

1. 用户从左侧菜单进入“学习”，客户端读取当前自然日的 1 条 AI 基础视频和文字总结。
2. 用户点击“在当前页观看”后在工作台页内播放器加载视频来源；打开视频本身不自动标记完成。
3. 用户点击“完成今日学习”后保存当前日期、内容 ID 和完成状态；再次点击可取消完成。
4. 用户填写备注并点击“保存备注”后保存原文备注和更新时间；同一天再次保存覆盖该日期的备注。
5. 学习页按日期倒序展示历史记录，显示完成状态和备注摘要。

### 5.6 多端同步

1. 用户在“我的”点击“使用邮箱登录”，输入有效邮箱后，客户端向 Supabase 发送免密登录链接；链接使用隐式回调流程，支持从手机邮件客户端或浏览器回到已部署的工作台页面并自动恢复会话。
2. 用户在部署后 HTTPS 地址打开邮件链接，Supabase 创建会话；客户端读取当前账号的云端工作台状态。
3. 云端无状态快照时，客户端上传当前设备的本机记录；云端状态更新时间晚于本机时，用云端状态覆盖本机初始示例或较旧数据并刷新页面。
4. 已登录用户每次修改记录后先保存到本机，再在 700 毫秒内异步上传完整工作台状态快照；上传成功显示“已同步”，失败显示“同步失败 · 数据已保存在本机”。

### 5.7 知识库

1. 用户从左侧菜单进入“知识库”，默认查看目录和全部文章；目录包含“全部”、工作与效率、学习笔记、健康与生活、灵感以及已有文章的自定义分类，并显示各分类文章数量。
2. 用户点击“记录到知识库”，填写记录内容；点击“生成标题”后，系统取正文第一句或前 24 个字符生成标题，用户可继续编辑标题。
3. 用户填写或选择分类、添加备注、选择一张图片后点击“保存文章”。正文少于 5 个字符时不允许保存。
4. 客户端将图片压缩为 JPEG 数据后保存；单张压缩后的数据超过 1.5 MB 时不保存图片，并提示用户选择更小的图片。
5. 保存成功后进入该文章详情页，展示标题、分类、创建时间、正文、备注和图片；返回目录后按创建时间倒序展示。
6. 用户可在文章详情中删除文章；确认删除后从本机和知识库文章表中移除该文章。
7. 用户在本对话发送“记录到知识库”及正文时，Codex 生成标题、分类和可选备注，并调用受保护的 `record-knowledge` 函数。函数校验录入密钥、正文长度和目标邮箱后，以 `assistant` 来源写入文章表。
8. 手机端登录相同邮箱后，在登录完成和每次进入知识库时读取文章表；本机旧文章在首次读取时迁移至文章表，文章表结果按创建时间倒序覆盖本机展示缓存。

## 8. 交互规则

- 全局导航固定为左上角汉堡按钮；点击后从左侧展开模块菜单，点击遮罩、关闭按钮或某一模块后收起菜单。
- 首页不展示“个人工作台”眉题文案和韩语学习卡片；韩语仅通过左侧菜单进入。
- 首页运动区域先选择运动类型，再填写时长或距离至少一项，点击“保存运动”后保存；同日再次保存时以最新填写内容覆盖当天记录。
- 运动详情仅聚合用户本地时区当前自然月的记录；总时长为全部时长之和，总距离为全部距离之和并保留一位小数，按日记录按日期倒序展示。
- 运动详情优先展示“记录今天”表单，表单下方依次展示“本月汇总”和“本月记录”。
- 本月记录以当前自然月日历展示；存在运动记录的日期显示对应运动图标。点击任一日期后，在日历下方展示当天全部运动类型、徒步路线、时长和距离；无记录日期显示“当天没有运动记录。”
- 运动类型为徒步时，首页和运动详情均显示“徒步地点或路线”输入框；未填写时点击保存提示“请填写徒步地点或路线”。徒步月度记录在日期后展示路线名称。
- 首页体重区域以参考体重每 0.1 kg 为步长生成 5 个选项；点击其中一个数值即保存为当天体重，再次选择其他数值则更新当天体重。
- 首页体重快捷选择固定分三行展示：第一行是昨天体重减 0.2 kg 和减 0.1 kg，第二行是可点击的“昨天体重”，第三行是昨天体重加 0.1 kg 和加 0.2 kg。
- AI 学习模块每天只展示 1 个视频，按用户本地时区在 00:00 切换当天内容；视频摘要至少包含 3 条可执行的初学者要点。
- 学习完成状态和备注按日期保存；保存备注不改变完成状态，打开视频不自动改变完成状态。
- 知识库默认按“全部”展示，目录由“全部”、4 个默认分类和已有文章分类组成；分类按钮显示该分类下文章数量，点击后仅展示对应文章。
- 新建知识库文章时，正文、标题、分类和备注可随时编辑；点击“生成标题”后以正文第一句或前 24 个字符填入标题。选择图片或处理图片时必须保留已填写的表单内容。
- 知识库正文少于 5 个字符时，点击保存提示“请至少填写 5 个字的记录内容”；保存成功提示“已记录到知识库”并进入文章详情。
- 知识库仅支持为每篇文章保存 1 张图片；图片缩放至最长边 1280 像素并压缩为 JPEG。压缩结果超过 1.5 MB 时不附加该图片，保留文章表单内容。
- 点击文章卡片进入详情；点击“删除文章”后需弹出“删除这篇文章后无法恢复，确定删除吗？”确认框，确认后提示“文章已删除”。
- 自动录入时 Codex 必须保留用户提供的正文原意；未指定分类时使用“学习笔记”或“未分类”，标题限制在 60 个字符以内。自动录入成功后返回文章 ID 和创建时间；失败时不得伪称已记录。
- 记录类主按钮使用动词：`记录饮水`、`保存运动`、`保存体重`、`标记已完成`。
- 8 个杯子按从左到右编号；点击空杯将其标为完成，点击已完成杯需确认“取消这一杯的饮水记录？”后取消；每杯固定为 250 ml。
- 喝水详情默认展示最近 7 个自然日；本周累计饮水量为该 7 天毫升数之和，日均杯数保留一位小数，达标天数统计杯数等于 8 的日期。
- 护肤任务完成后显示“已完成”；再次点击取消当天完成状态。新增护理需填写不重复的名称，图标可留空并自动使用 `✨`；新增后立即在今天任务清单和本月日历中生效。
- 护肤本月日历的每个日期显示当天所有已完成护理的图标；点击日期后以 Toast 显示当天护理名称，无记录时提示“无护理记录”。
- 首页运动未选择类型时提示：`请选择运动类型`；时长和距离均未填写时提示：`请填写运动时长或距离`；数值超出范围时提示对应可填写范围。体重填写无效时提示：`请输入 20.0-300.0 kg 的体重`。
- 韩语学习页支持第 1-10 课切换，当前课次本机保存；课次页学习区块默认显示“单词”，单词、句子条目均有播放发音按钮，生词按钮的选中状态可跨设备同步。
- 所有模块的视频入口均使用当前工作台的页内播放器，视频不可自动播放，不打开新窗口或离开当前页面；关闭播放器后清空嵌入来源。
- 每课视频区固定展示“课文讲解”和“练习册讲解”两类。仅 `verified` 状态的练习册视频可在页内播放器加载，`collection_code_only` 状态展示抖音合集口令和页内搜索入口，`unmatched` 状态展示待匹配提示和博主作品页内入口。
- 韩语学习页和课次页顶部不显示“首尔大学韩国语”文案。
- 移动端以 320-480 CSS 像素宽度为适配范围，触控元素可点击区域不小于 44×44 CSS 像素。
- 手机浏览器访问已部署 HTTPS 地址后可添加到主屏幕；从桌面图标启动时以独立窗口显示。应用壳可离线打开，登录和数据同步需联网。
- 免密登录链接的回跳地址必须已配置在 Supabase 的 Redirect URLs 中；当前应用通过 `location.origin + location.pathname` 作为回跳地址。

## 9. 异常场景

| 场景 | 处理与文案 |
| --- | --- |
| 无权限 | 禁止访问他人数据，提示“你没有查看这条记录的权限”。 |
| 数据为空 | 保留模块入口，显示对应空状态，不显示伪造趋势或记录。 |
| 数据过多 | 历史列表按日期分页，每次加载 20 条；月视图只渲染当前月。 |
| 网络失败 | 本地暂存未提交操作，显示“暂时无法同步，网络恢复后将自动重试”；重试三次后显示“同步失败，请手动重试”。 |
| 登录服务不可用 | 显示“同步服务暂时不可用 · 数据保存在本机”，不阻止本机记录。 |
| 邮箱格式错误 | 点击发送链接时提示“请输入有效的邮箱地址”。 |
| 登录链接发送失败 | 提示“登录链接发送失败，请检查邮箱或稍后重试”。 |
| 登录链接失效或在其他设备使用 | 清理回跳地址中的认证错误信息，提示“登录链接已失效或已被使用，请重新发送登录链接”。 |
| 本机文件登录 | 使用 `file://` 打开时提示“请在部署后的 HTTPS 地址打开后再登录”。 |
| 云端状态读取失败 | 显示“云端记录读取失败 · 数据仍保存在本机”，不覆盖本机数据。 |
| 发音服务失败 | 保留单词和句子内容，提示“发音暂时无法播放，请检查网络后重试”；不影响标记生词。 |
| 课程视频未匹配 | 练习册视频未匹配时显示“该课尚未核验到公开匹配视频”，提供“查看博主作品”入口。 |
| 课文合集无法解析 | 展示“抖音合集口令：8ao3lFnbn89”和搜索入口，不把未核验搜索结果作为课次视频。 |
| 当天学习内容为空 | 显示“今天的学习内容正在准备中”，提供“重新加载”按钮。 |
| 知识库为空 | 显示“这个分类还没有文章。点击‘记录到知识库’，把值得回看的内容留下来。”。 |
| 知识库正文过短 | 不保存，提示“请至少填写 5 个字的记录内容”。 |
| 知识库图片格式无效 | 不处理图片，提示“请选择图片文件”。 |
| 知识库图片读取或处理失败 | 保留已填写的正文、标题、分类和备注，提示“图片读取失败，请重新选择”或“图片处理失败，请重新选择”。 |
| 知识库图片过大 | 不附加图片，保留已填写内容并提示“图片过大，请选择更小的图片”。 |
| 删除知识库文章 | 弹出二次确认；取消时不删除，确认后从本机和后续云端快照移除。 |
| 自动录入密钥无效 | 函数拒绝写入并返回“录入密钥无效”；Codex 提示“知识库自动记录未配置完成”。 |
| 自动录入目标用户不存在 | 函数拒绝写入并返回“未找到该邮箱对应的已登录用户”；提示用户先在工作台使用该邮箱登录一次。 |
| 自动录入超时或网络失败 | Codex 明确提示“知识库自动记录失败，请稍后重新发送”；不生成本地伪记录。 |
| 视频链接失效 | 显示“视频暂时无法打开，请稍后重试”，保留文字总结和备注功能。 |
| 来源禁止嵌入 | 保持在当前工作台页面，播放器区域显示“视频暂时无法在当前页加载，请稍后重试”，不自动跳转到来源站点。 |
| 首页运动缺少数据 | 未选择类型时提示“请选择运动类型”；时长和距离均为空时提示“请填写运动时长或距离”。 |
| 点击无运动日期 | 在日历下方显示“当天没有运动记录。”，不影响当前月汇总。 |
| 徒步记录缺少路线 | 点击保存时提示“请填写徒步地点或路线”，保留已填写时长和距离。 |
| 新增护理内容无效 | 名称为空提示“请输入护理内容”；超过 20 个字提示“护理内容最多 20 个字”；名称重复提示“该护理内容已存在”。 |
| 备注超长 | 超过 1000 个字符时禁止保存，提示“备注最多输入 1000 个字符”。 |
| 重复提交 | 保存按钮提交后禁用至结果返回；服务端按请求 ID 去重。 |
| 并发操作 | 同一记录产生版本冲突时提示“记录已在其他设备更新，已显示最新内容”。 |
| 超时 | 请求超过 10 秒提示“请求超时，请检查网络后重试”。 |
| 撤销或取消 | 删除和取消完成均需二次确认；关闭表单不保存未提交内容。 |
| 旧版本兼容 | 新字段提供默认值；旧客户端遇到未知课程字段时忽略展示。 |
| 多端同步 | 以账号为同步范围；同步失败不覆盖本地未上传记录。 |
| 异常数据 | 数值超范围或日期无效时拒绝保存并明确提示可填写范围。 |

## 11. 验收标准

1. 用户打开应用后默认进入“今天”，仅看到当天饮水、运动、体重和护肤四项内容，不显示韩语学习摘要。
2. 首页和喝水详情均显示 8 个可点击杯子；点击任一空杯后，该杯显示完成状态、总进度增加 1 杯/250 ml，刷新页面后状态仍存在。
3. 喝水详情显示最近 7 天每日杯数和毫升数，并正确展示累计饮水量、日均杯数和达标天数；点击当天杯子后，该日期和汇总数据即时更新。
4. 首页仅展示喝水、运动、体重、护肤四项，且不显示“个人工作台”眉题文案或韩语学习内容。
5. 首页可选择羽毛球、游泳、徒步、跑步，填写时长或距离任一项并保存；选择徒步时必须填写地点、山峰或路线名称。刷新页面后可恢复当天的运动类型、时长、距离和徒步路线。
6. 首页显示基于前一天体重生成的 5 个参考值，相邻值相差 0.1 kg；点击后保存当天体重，再次选择时更新当天记录。
7. 首页的喝水、运动、体重、护肤模块均不显示辅助副标题；体重参考值按“较低两值一行、昨天体重一行、较高两值一行”排列。
8. 体重仅接受 20.0-300.0 kg 且最多一位小数；成功保存后可在历史中看到该条记录，并在最近 7 条数据折线图中显示。
9. 护肤页默认显示当天的眼膜、面膜、冻膜、泥膜、基础护肤五项及其图标；用户可添加名称和图标，刷新页面后新增任务仍存在。
10. 护肤本月页按日期展示当天完成护理的图标；点击日期可查看当天已完成的护理名称。
11. 运动详情从上至下展示“记录今天”“本月汇总”“本月记录”；本月记录以日历显示，日期内展示对应运动图标；点击日期后在日历下方展示当天明细，徒步记录显示路线名称；保存当天记录后所有汇总即时更新。
12. 韩语学习页可在第 1-10 课间切换，刷新页面后恢复上次打开课次；韩语学习页和课次页顶部均不显示“首尔大学韩国语”。
13. 每课视频区均展示课文讲解和练习册讲解；已核验练习册视频在当前页的播放器中加载，未匹配课次明确显示待匹配，课文合集口令未解析为直达链接时保留口令和页内搜索入口。
14. 每个单词和句子均可播放韩语发音，单词可独立标记或取消生词状态；原型显著标识内容示例，正式版只展示已授权内容源中的完整课程数据。
15. 学习模块每天只显示 1 个 AI 视频，视频在当前页播放器中打开，页面同时展示不少于 3 条文字总结；完成状态和备注刷新页面后仍可恢复，并可按日期查看历史记录。
16. 左侧菜单包含“知识库”入口。进入后可按“全部”或分类目录筛选文章，目录显示每个分类的文章数量，文章按创建时间倒序展示。
17. 用户填写至少 5 个字符的正文后可保存知识库文章；未填写标题时自动生成标题，用户可手动修改；详情页显示标题、分类、创建时间、正文、备注和已保存图片。
18. 用户填写文章后选择图片，正文、标题、分类和备注均不会丢失；压缩后的图片不超过 1.5 MB 时可随文章保存，超过时给出明确提示并保留表单内容。
19. 用户可删除知识库文章，取消确认不删除；确认删除后目录数量、文章列表和详情立即更新，刷新页面后文章不再存在。
20. 用户使用已登录邮箱打开工作台后，知识库从 `knowledge_articles` 表读取文章；本机旧文章会迁移一次，后续同账号其他设备可读取相同文章。
21. 向 Codex 发送“记录到知识库”及至少 5 个字符正文后，函数使用受保护密钥写入该邮箱账户；重新打开知识库后可看到自动生成标题、分类、创建时间与正文。
22. 在 320、375、390、430 CSS 像素宽度下，导航、按钮、内容均无遮挡、无横向滚动且可操作。
23. 离线、超时、权限不足、空数据、保存成功和保存失败状态均有对应页面或提示文案。
24. 登录同一账号的未来桌面端与移动端读取同一份云端数据，单条记录同步延迟目标不超过 5 秒（网络正常时）。
25. 用户输入有效邮箱后可收到免密登录链接；从手机邮件客户端或浏览器打开已配置的 HTTPS 回跳地址后，“我的”页显示当前邮箱，无需再次登录；其他设备登录同一邮箱后可恢复该账号云端工作台状态。
26. 使用手机浏览器打开已部署 HTTPS 地址时可添加到主屏幕；从桌面图标启动后显示个人工作台名称和小丑舞台图标，离线时仍可打开应用壳。

## 12. 不做范围

- 本期不开发桌面端页面、Web 管理后台或家庭成员共享。
- 本期不提供营养热量计算、运动路线轨迹、设备自动同步或医疗建议。
- 本期不生产或购买《首尔大学韩国语》教材内容、视频版权；仅接入获得授权的课程内容与链接。
- 本期不提供视频托管、下载、自动转写或替代原视频的播放服务；仅保存来源链接、总结和个人学习记录。
- 本期不提供知识库全文检索、文章编辑、批量导入导出、附件管理、多人协作、回收站或图片云端对象存储。
- 本期不包含社交排名、公开动态、成就体系或付费功能。

## 假设

- 假设用户使用个人账号登录，且手机系统时间可作为当日记录的默认时区依据。
- 假设韩语课程内容、中文释义和教学视频均由拥有相应授权的内容方提供。
- 假设饮水日目标初始为 2000 ml，后续可在“我的”页修改。
- 假设每杯饮水固定为 250 ml，且用户每天以 8 杯作为默认目标。
- 假设正式版接入具有韩语语音能力的 TTS 服务；HTML 原型使用浏览器语音朗读作为演示兜底。
- 假设课文讲解合集为公开可访问内容；当前仅得到抖音合集口令 `8ao3lFnbn89`，正式接入前需要补充可核验的直达 URL 或授权接口。
- 假设练习册视频以抖音账号“韩语坞灿_lanlan”的公开作品为准；当前已核验第 1、5、6、7 课的公开链接，其余课次待核验。
- 假设每日 AI 视频来自可公开访问且支持页内嵌入的来源；当前原型首日内容使用用户提供并已核验的抖音公开视频链接。来源站点可能限制嵌入，正式版需要接入具备嵌入授权的播放器或视频接口。
- 假设首页快捷运动记录的时长和距离至少填写一项；用户可后续在运动详情补充其余字段。
- 假设自定义护理任务仅包含名称和单个图标，不支持设置周期、提醒、排序或删除。
- 假设 Supabase Email Provider 已启用，并已配置应用的正式 HTTPS 地址为 Site URL 和 Redirect URL。
- 假设本期采用整份工作台状态快照进行同步；并发修改时以最后成功上传的快照为准。
- 假设知识库文章以个人资料沉淀为目的，每篇文章只附带一张图片，并以独立文章表保存；页面本机缓存仅用于离线浏览和迁移旧记录。
